# SANAD MVP — Prototype

## التشغيل
1. فك ضغط `SANAD_MVP.zip`.
2. افتح `index.html` في متصفح حديث (Chrome أو Firefox أو Edge).
3. جرّب تغيير اللغة، البحث والتصفية، وفتح نموذج طلب المساعدة.

## محتويات المشروع
- `index.html`: هيكل الموقع.
- `styles.css`: التصميم المتجاوب.
- `app.js`: الترجمات والتفاعلات والبيانات التجريبية.

## تنبيه مهم
هذه واجهة تجريبية Front-end فقط:
- لا يوجد تسجيل دخول حقيقي.
- لا توجد قاعدة بيانات أو حفظ للطلبات.
- لا يتم إرسال النماذج أو الرسائل.
- الحالات المعروضة وهمية للتوضيح.
- لا تدخل معلومات شخصية أو مصرفية حقيقية.

## خطة التشغيل خطوة بخطوة
### المرحلة A — المعاينة المحلية
افتح `index.html` مباشرة. لا تحتاج إلى تثبيت برامج أو دفع رسوم.

### المرحلة B — نشر واجهة تجريبية
يمكن لاحقاً نشر الملفات الثابتة عبر استضافة مجانية مناسبة، بعد مراجعة شروط الخدمة وإعداد سياسة خصوصية واضحة. لا تستقبل بيانات حقيقية في هذه المرحلة.

### المرحلة C — بناء الخدمة الحقيقية
قبل استقبال مستخدمين فعليين:
1. اختيار كيان قانوني ومسؤوليات تشغيلية واضحة.
2. إعداد شروط الاستخدام وسياسة الخصوصية وإجراءات GDPR.
3. إنشاء backend وقاعدة بيانات.
4. تطبيق صلاحيات دقيقة وفصل مستندات التحقق عن الملفات العامة.
5. إضافة تسجيل دخول آمن ورسائل ومراجعة إدارية.
6. اختبار أمني وقانوني مستقل.
7. تجربة مغلقة بدعوات محدودة.
